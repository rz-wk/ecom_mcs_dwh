# Dashboard `E-commerce Customer Journey`

## Цель

>Показать Customer Journey от общего состояния пользовательского потока до коммерческой детализации.


## Структура dashboard

Состоит из четырёх секций:

1. Главное (обзор)
2. Воронка и конверсия
3. Сессии и пользователи
4. Продукты, категории и продажи

Всего 18 графиков.

Визуальная иерархия:

`KPI` -> `trend` -> `comparison` -> `detail`

Область применения Native Filters

| Фильтр    | Обзор | Воронка | Сессии | Продукты и продажи |

| Период    |     ✓ |       ✓ |      ✓ |                  ✓ |

| Бренд     |     — |       ✓ |      — |                  ✓ |
| Продукт   |     — |       — |      — |                  ✓ |

Cross-filtering используется для перехода от агрегированного представления к детализации там, где это имеет аналитический смысл.


## Сортировка и форматирование

- Временные ряды сортируются по дате по возрастанию;
- Рейтинговые графики сортируются по соответствующему показателю по убыванию;
- Top-N применяется после сортировки по целевой метрике;
- Для конверсионных метрик используется процентный формат;
- Денежные показатели отображаются в рублях;
- Количественные показатели отображаются как целые значения.
