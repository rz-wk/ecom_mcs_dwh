# Dataset `mart_sessions`

## Назначение

Витрина для анализа пользовательских сессий и поведения внутри сессии.

Используется для оценки активности, длительности сессий и количества покупок.

## Grain

Одна строка соответствует одной пользовательской сессии.

## Поля

| Поле                       | Тип                | Описание                        |
| -------------------------- | ------------------ | ------------------------------- |
| `session_id`               | String             | Идентификатор сессии            |
| `user_id`                  | UInt32             | Идентификатор пользователя      |
| `session_start`            | DateTime64(3, UTC) | Начало сессии                   |
| `session_end`              | DateTime64(3, UTC) | Конец сессии                    |
| `session_duration_seconds` | Int64              | Длительность сессии в секундах  |
| `events_count`             | UInt64             | Количество событий              |
| `views_count`              | UInt64             | Количество просмотров           |
| `carts_count`              | UInt64             | Количество добавлений в корзину |
| `remove_from_cart_count`   | UInt64             | Количество удалений из корзины  |
| `purchases_count`          | UInt64             | Количество покупок              |
| `products_count`           | UInt64             | Количество продуктов            |
| `purchase_amount`          | Decimal(38, 2)     | Сумма покупок в сессии          |
| `session_date`             | Date               | Дата сессии                     |

## Использование в dashboard

| График              | Показатель                        |
| ------------------- | --------------------------------- |
| Сессии              | `COUNT(session_id)`               |
| Событий за сессию   | `AVG(events_count)`               |
| Покупок за сессию   | `SUM(purchases_count) / COUNT(*)` |
| Длительность сессии | `AVG(session_duration_seconds)`   |
