# Dataset `mart_funnel`

## Назначение

Витрина для анализа customer journey по этапам воронки, категориям и брендам.

Используется для анализа количества событий на этапах воронки, их динамики и сравнения категорий.

## Grain

Одна строка соответствует комбинации:

`дата + категория + бренд + этап воронки`

## Поля

| Поле                 | Тип                    | Описание                    |
| -------------------- | ---------------------- | --------------------------- |
| `event_date`         | Date                   | Дата события                |
| `category_id`        | UInt64                 | Идентификатор категории     |
| `category_root_name` | String                 | Корневая категория          |
| `category_leaf_name` | String                 | Конечная категория          |
| `brand`              | LowCardinality(String) | Бренд                       |
| `funnel_stage`       | LowCardinality(String) | Этап воронки                |
| `stage_count`        | UInt64                 | Количество событий на этапе |
| `revenue`            | Decimal(38, 2)         | Выручка                     |

## Использование в dashboard

| График                    | Показатель                                       |
| ------------------------- | ------------------------------------------------ |
| События по этапам         | `SUM(stage_count)`                               |
| Динамика воронки          | `SUM(stage_count)` с разбивкой по `funnel_stage` |
| Топ категорий по покупкам | `SUM(stage_count)` при `funnel_stage = purchase` |

### Фильтры

- Период
- Категория
- Бренд

### Особенности

`funnel_stage` определяет этап customer journey. Для анализа покупок используется фильтр:

```text
funnel_stage = purchase
```
