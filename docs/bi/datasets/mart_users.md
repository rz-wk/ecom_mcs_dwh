# Dataset `mart_users`

## Назначение

Витрина для анализа активности пользователей во времени.

Содержит агрегированные показатели событий, взаимодействий с товарами и покупок на уровне пользователя.

## Grain

Одна строка соответствует комбинации:

`дата + пользователь`

## Поля

| Поле                     | Тип            | Описание                        |
| ------------------------ | -------------- | ------------------------------- |
| `event_date`             | Date           | Дата событий                    |
| `user_id`                | UInt32         | Идентификатор пользователя      |
| `event_count`            | UInt64         | Общее количество событий        |
| `view_count`             | UInt64         | Количество просмотров           |
| `cart_count`             | UInt64         | Количество добавлений в корзину |
| `remove_from_cart_count` | UInt64         | Количество удалений из корзины  |
| `purchase_count`         | UInt64         | Количество покупок              |
| `revenue`                | Decimal(38, 2) | Выручка                         |
| `source_session_count`   | UInt64         | Количество исходных сессий      |

## Использование в dashboard

| График       | Показатель       |
| ------------ | ---------------- |
| Пользователи | `COUNT(user_id)` |

### Фильтры

- Период

### Особенности

- Dataset используется для определения количества пользователей в выбранном периоде. Детальная пользовательская аналитика доступна на уровне `event_date + user_id`.
