# Dataset `mart_products`

## Назначение

Витрина для анализа эффективности продуктов на этапах customer journey.

Позволяет сравнивать просмотры, добавления в корзину, покупки и выручку по продуктам и категориям.

## Grain

Одна строка соответствует комбинации:

`дата + продукт`

## Поля

| Поле                     | Тип              | Описание                        |
| ------------------------ | ---------------- | ------------------------------- |
| `event_date`             | Date             | Дата события                    |
| `product_id`             | UInt32           | Идентификатор продукта          |
| `category_id`            | UInt64           | Идентификатор категории         |
| `category_root_name`     | String           | Корневая категория              |
| `category_leaf_name`     | String           | Конечная категория              |
| `brand`                  | Nullable(String) | Бренд                           |
| `view_count`             | UInt64           | Количество просмотров           |
| `cart_count`             | UInt64           | Количество добавлений в корзину |
| `remove_from_cart_count` | UInt64           | Количество удалений из корзины  |
| `purchase_count`         | UInt64           | Количество покупок              |
| `revenue`                | Decimal(38, 2)   | Выручка                         |

## Использование в dashboard

| График                  | Показатель                                                                                                 |
| ----------------------- | ---------------------------------------------------------------------------------------------------------- |
| Просмотры               | `SUM(view_count)`                                                                                          |
| Корзины                 | `SUM(cart_count)`                                                                                          |
| Эффективность продуктов | `SUM(view_count)`, `SUM(cart_count)`, `SUM(remove_from_cart_count)`, `SUM(purchase_count)`, `SUM(revenue)` |
| Конверсия               | `SUM(cart_count) / NULLIF(SUM(view_count), 0)`                                                             |
| Конверсия               | `SUM(purchase_count) / NULLIF(SUM(view_count), 0)`                                                         |

### Фильтры

- Период
- Категория
- Бренд
- Продукт

### Особенности

- `brand` допускает `NULL`.
- Конверсионные показатели рассчитываются непосредственно в Superset на агрегированных данных.
