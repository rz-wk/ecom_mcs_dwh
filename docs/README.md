# Документация E-commerce DWH

Документация описывает архитектуру и реализацию аналитического DWH для исследования пользовательского поведения в e-commerce: от загрузки исходных событий до формирования витрин и анализа воронки.

Документы отражают текущую реализацию проекта. При расхождении концептуального описания с кодом приоритет имеет фактическая реализация.

## Оглавление

- [Архитектура системы](architecture/architecture.md) — компоненты, зоны ответственности и технологический стек.
- [Поток данных](architecture/data_flow.md) — последовательность обработки данных от исходных CSV-файлов до аналитических витрин.

### Модель данных

- [Схема данных](data_model/schema.md) — структура слоёв DWH, аналитические объекты и связи между ними.
- [Словарь данных](data_model/data_dictionary.md) — описание таблиц, полей, типов и семантики данных.

### Качество данных

- [Data Quality](data_quality/README.md) — архитектура контроля качества, матрица проверок, стандарты покрытия и процедуры диагностики сбоев.

### Происхождение данных

- [Data Lineage](data_lineage/README.md) — связи между источником, слоями хранения и аналитическими моделями; интеграция с OpenMetadata, эмиттеры и эксплуатационные процедуры.
