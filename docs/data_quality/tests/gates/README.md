# Python-гейты границ этапов

Гейт — Airflow-таск, запускающий модуль из `src/validation/`. Модуль выполняет доступные проверки, отправляет результаты в OM в режиме best-effort и затем завершает работу исключением, если обнаружены нарушения. В этом случае таск получает статус `Failed`, а нисходящие таски не запускаются.

Общие характеристики:

- Гейты только читают данные и безопасны для повторного запуска;
- Если CSV отсутствует, например при пустом месяце бэкфилла, гейт пропускает обработку без ошибки;
- Для Python-кейсов dimension задаётся явно в `src/lineage/dq.py` (см. [naming.md](../../naming.md));
- Эталон берётся из фактических данных: журнала, контракта или второй стороны конвейера, а не из произвольной константы.
