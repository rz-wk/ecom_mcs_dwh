# Generic-тесты слоя Core

**Файл:** `dbt/models/core/schema.yml`, раздел `sources`.

| Тест | Проверка | Dimension | Что означает провал |
|---|---|---|---|
| `not_null` для `event_id` | Идентификатор заполнен | Completeness | В Core попали данные без ключа; проверить гейт `test_ods_core` |
| `unique` для `event_id` | Ключ уникален | Uniqueness | Возможен повторный прогон Spark или дублирование batch |
| `not_null` для `event_time` | Время заполнено | Completeness | Некорректные строки прошли предыдущие этапы |
| `not_null` для `user_id` | Пользователь заполнен | Completeness | Некорректные строки прошли предыдущие этапы |
| `not_null` для `event_type` | Тип события заполнен | Completeness | Некорректные строки прошли предыдущие этапы |

## Диагностика

- Если результат расходится с гейтом `test_ods_core`, сначала изучить его лог и входные данные;
- Если гейт зелёный, но `unique(event_id)` падает, проверить генерацию `event_id` и повторные запуски Spark;
- Если падает `not_null`, проверить очистку и преобразование данных на этапе PySpark.
