# Singular-тесты Core

## `core_integrity` — Integrity

- **Файл:** `dbt/tests/core_integrity.sql`.
- **Проверка:** в `fact_events` нет NULL в обязательных полях, отрицательных цен и недопустимых `event_type`. Несколько связанных условий проверяются одним запросом.
- **Провал:** нарушение не обнаружено на предыдущих этапах. Проверить лог гейта и этап PySpark.

Проверка частично пересекается по области контроля с generic-тестами и гейтами. Её назначение — объединённый контроль целостности таблицы; при сопровождении следует сохранять явное распределение ответственности за отдельные свойства в [матрице](../README.md).

## `core_reconciliation` — Consistency

- **Файл:** `dbt/tests/core_reconciliation.sql`.
- **Проверка:** `_source_file`, `_batch_date` и `event_date` не равны NULL.
- **Провал:** в Core записаны неполные batch-метаданные.
- **Действие:** проверить запись и преобразование данных в Core.
